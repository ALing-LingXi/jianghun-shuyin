护理管理项目组前端开发岗位技术栈要求
一、基础核心层
1. 前端基础（HTML/CSS/JS/ES6+）
- 熟练使用语义化HTML、Flex/Grid布局，可精准还原设计稿生成web页面
- 掌握Less基础用法：变量、嵌套、混合、作用域
- 掌握ES6+语法：箭头函数、解构赋值、模块化、展开运算符
- 理解闭包、作用域、异步编程，熟练使用Promise、async/await
- 熟练使用数组常用方法：map、filter、reduce、find等

2. React + Hooks 核心
- 熟练编写函数组件、类组件、熟悉JSX语法
- 熟练使用基础Hooks：
  useState：常规状态管理
  useEffect：处理副作用、模拟生命周期，正确管理依赖，杜绝无限循环、内存泄漏
  useRef：操作DOM、存储可变数据
  useMemo、useCallback：做渲染性能优化，减少无效重渲染
  useContext、useReducer：实现跨组件传值、复杂状态管理
- 具备自定义Hooks能力，可封装请求、表单、防抖节流、定时器等通用逻辑

3. TypeScript 专项（禁止滥用any）
- 熟练使用interface、type定义类型，掌握基础类型、联合类型、可选/只读属性
- 能对组件Props、函数、接口返回数据、Hooks做完整类型约束
- 理解枚举、泛型基础、类型推导、非空断言、类型断言使用场景

4、状态管理与组件通信
- 父子组件通信：Props传递、回调函数触发事件
- 跨层级/跨页面通信：useContext、Taro全局变量、主流状态管理库
- 熟练使用状态库 Redux
- 可独立维护全局状态：用户信息、登录态、全局配置、公共参数等

5. 网络请求与数据处理
- 熟练掌握Axios框架，完成实例创建、请求/响应拦截器封装、基础配置
- 实现Token统一管理、请求头携带、自动刷新Token、登录过期统一处理
- 统一接口错误码处理、异常捕获、全局提示、请求加载状态管理
- 按照TS规范定义接口请求/响应数据类型，实现字段映射、数据格式化

6. Webpack 构建基础
- 理解Webpack核心概念：entry、output、loader、plugin
- 能看懂项目现有Webpack配置，理解路径别名、环境变量、样式处理、多端适配配置
- 区分开发环境、测试环境、生产环境打包逻辑

二、业务开发（H5 + UI组件库）
1. Taro 框架
- 了解Taro基于React语法编译为小程序、H5等多端的核心原理
- 熟悉Taro项目目录结构、全局配置app.config.ts、页面单独配置
- 掌握Taro路由：页面跳转、路由传参、TabBar、页面栈管理
- 熟悉Taro专属生命周期：useDidShow、useDidHide等
- 可独立开发列表、表单、详情、弹窗、个人中心等常规多端页面
- 掌握多端兼容写法、条件编译，处理小程序与H5之间API、样式差异

2. Taro UI 组件库（移动端H5/小程序）
- 熟练使用常用组件：Button、Input、List、Modal、Picker、Toast、Loading、Form
- 掌握表单校验、数据回显、提交、重置逻辑
- 可对组件做样式覆盖、二次封装，保证多端样式表现一致

3. Ant Design 组件库（护理管理PC/H5）
- 熟练使用Table、Form、Modal、Drawer、Select、Pagination、Upload等核心组件
- 实现表格分页、筛选、排序、批量操作；表单联动、自定义校验、文件上传
- 掌握组件按需引入、基础主题定制、样式隔离方案

三、部署运维层（Webpack打包 + PM2 + Node部署）
1. 项目打包构建
- 熟练执行打包命令：web环境、H5等环境打包
- 理解打包产物dist目录结构、静态资源路径规则
- 解决打包后页面白屏、资源加载失败、跨域、样式丢失等问题

2. PM2 + Node 服务部署
- 了解Node服务部署基本流程
- 熟练使用PM2常用命令：启动、停止、重启、查看进程、查看日志
- 看懂并简单配置pm2-app.json：端口、环境变量、日志输出、进程配置
- 了解Nginx基础命令，反向代理、跨域配置
- 完整独立流程：代码打包 → 上传服务器 → PM2部署启动 → 线上功能验证
